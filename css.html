Título principal

Este archivo demuestra estilos para encabezados y texto usando CSS en la misma página.

Encabezado H2

Sirve para secciones importantes.

h2 { ... }

Encabezado H3

Se usa para subsecciones dentro de H2.

h3 { ... }

Estilo del texto

Se ajustó color, espaciado y line-height para mejor lectura.

p { ... }

Ejemplo rápido

Si quieres que tus títulos se vean más claros: usa jerarquía (H1 → H2 → H3), aplica colores coherentes y mantén el contraste.
